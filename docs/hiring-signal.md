# Hiring Signal

This repository is meant to support hiring conversations for Java roles that
need maintainable design and clear trade-off reasoning.

## What It Proves

- Ability to select patterns from actual change pressure.
- Awareness that abstraction has cost.
- Communication of design decisions without hiding behind terminology.

## Role Fit

Best aligned with Java backend, application architecture, refactoring, and code
quality roles where maintainability matters.
