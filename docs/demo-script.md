# Demo Script

Use this short script to present the repository in a technical interview.

## 3-Minute Walkthrough

1. Start with the goal: practical Java design patterns tied to backend
   scenarios.
2. Show Command, State, and Specification first because they demonstrate
   workflow, lifecycle, and rule composition.
3. Explain that each pattern includes tests so the behavior is reviewable.
4. Close with the next step: Template Method for billing retry workflows.

## What To Emphasize

- Patterns are selected from business pressure.
- The repository avoids abstract examples with no domain context.
- Trade-offs matter as much as pattern names.

## Before The Interview

- Pick three patterns to discuss deeply.
- Prepare one example of when a pattern would be overengineering.
- Connect each pattern to a test that proves behavior.

## Avoid Saying

- "I used patterns because they are best practices." Instead, connect each
  pattern to a concrete change pressure.
- "This pattern is always better." Instead, explain the trade-off.
