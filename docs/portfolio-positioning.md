# Portfolio Positioning

This is a supporting design repository in the portfolio.

## What It Proves

- Object-oriented design vocabulary.
- Ability to select patterns from real change pressure.
- Restraint: examples stay small, tested, and practical.
- Trade-off thinking instead of pattern name-dropping.

## How To Present It

Present this repository after the main backend project when the conversation
turns to maintainability, extensibility, or design decisions.

## Best Interview Angle

Use Command, State, and Specification to show workflow, lifecycle, and
business-rule composition.
