# Hiring Manager One-Pager

## Project Positioning

A Java repository that explains design patterns through practical backend
engineering scenarios.

## Why It Is Relevant

Senior engineers need judgment around maintainability, abstraction, and change,
not only knowledge of pattern names.

## What It Demonstrates

- Practical use of patterns under real change pressure.
- Awareness of overengineering risks.
- Ability to explain trade-offs with tests and examples.

## Interview Hook

Ask when a pattern should be removed or replaced by simpler code.
