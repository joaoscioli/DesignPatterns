# Technical Scope

This file defines what the project is meant to prove and what it does not claim yet.

## In Scope

- Java design pattern examples.
- Pattern selection trade-offs.
- Anti-pattern guidance.
- Tests that clarify behavior and intent.

## Out of Scope for Now

- Exhaustive catalog of every GoF pattern.
- Enterprise-size framework abstractions.
- Production application deployment.
- Pattern usage without a clear change pressure.

## Scope Statement

The project is scoped to prove design judgment. The next milestone is adding
more before-and-after refactoring examples that show when a pattern earns its
complexity.
