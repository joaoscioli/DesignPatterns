# Live Review Script

Use this script when sharing the repository during an interview.

## Opening

This repository demonstrates design patterns as refactoring tools for backend business logic.

## Walkthrough order

1. Start with `README.md` to frame the catalog.
2. Pick one pattern and show the related tests first.
3. Explain the business smell that justifies the pattern.
4. Compare the benefit with the extra abstraction cost.
5. Close with when not to use the pattern.

## Strong signal

The goal is not to memorize pattern names, but to show judgment about changeability and testability.
