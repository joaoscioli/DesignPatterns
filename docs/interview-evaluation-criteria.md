# Interview Evaluation Criteria

Use these criteria to evaluate the project during a technical interview.

## Baseline Signal

- Names the patterns and describes their intent.
- Locates examples and supporting documentation.
- Explains the difference between a pattern and an anti-pattern.

## Strong Signal

- Starts from change pressure before choosing a pattern.
- Uses tests to explain behavior-preserving refactoring.
- Compares a pattern with simpler alternatives.

## Senior Signal

- Shows restraint around abstraction.
- Explains the maintenance cost of each design choice.
- Treats patterns as tools for change management, not as status symbols.
