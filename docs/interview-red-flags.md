# Interview Red Flags

Use this file to avoid weak signals during a technical interview.

## Avoid Saying

- "I used the pattern because it is a best practice."
- "More patterns always make code more professional."
- "This pattern is always better than a simple class."
- "The structure matters more than the behavior."

## Say Instead

- A pattern is useful when it reduces real change cost.
- Overusing patterns can make a small codebase harder to maintain.
- Simpler code is better when variation and lifecycle pressure are low.
- Tests should prove the behavior that made the pattern necessary.
