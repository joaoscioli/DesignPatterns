# Technical Elevator Pitch

This project is a Java design judgment lab. It uses design patterns to discuss
trade-offs, change pressure, refactoring safety, and when abstraction is worth
its cost.

## 30-Second Version

"I built this repository to show that I do not treat design patterns as recipes.
The goal is to explain when a pattern improves maintainability, when simple code
is better, and how tests can protect behavior during refactoring."
