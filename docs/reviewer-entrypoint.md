# Reviewer Entrypoint

Use this page when you have only a few minutes to evaluate the repository.

## First Three Files

- `README.md` for the project purpose and navigation.
- `docs/technical-scope.md` for what the project proves today.
- `docs/pattern-selection.md` for decision criteria.

## What To Look For

- Patterns explained through trade-offs, not memorized definitions.
- Examples that clarify when extra abstraction is worth the cost.
- Anti-pattern notes that show judgment under maintenance pressure.

## Strong Interview Signal

The repository is strongest when discussed as a design judgment lab: it shows how
to choose patterns from real change pressure instead of applying patterns by
habit.
