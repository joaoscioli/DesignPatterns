# Acceptance Criteria

This file defines what the next implementation slice must satisfy before it is
considered ready for review.

## Refactoring Example

- The initial code shows a real maintainability problem.
- Tests lock behavior before the pattern is introduced.
- The chosen pattern reduces change risk without hiding simple logic.
- Alternatives are documented with trade-offs.
- The final example is small enough to review quickly.

## Review Standard

The slice is ready when a reviewer can explain why the pattern was introduced,
what it improves, and when it would be the wrong choice.
