# 30-Second Pitch

This repository is a practical Java design patterns lab.

It demonstrates that I understand patterns as tools for solving change pressure,
not as names to decorate code. The examples are intentionally small, tested, and
connected to backend scenarios such as billing commands, subscription states,
business-rule specifications, notifications, and adapters.

In an interview, I would use this repository to discuss maintainability,
object-oriented design, trade-offs, and when a pattern would be overengineering.
