# Demo Readiness Checklist

Use this checklist before presenting the repository in a technical interview.

## Before The Demo

- Open `README.md`, `docs/reviewer-entrypoint.md`, and `docs/pattern-selection.md`.
- Pick one pattern and one anti-pattern to discuss.
- Prepare a before-and-after refactoring explanation.

## During The Demo

- Start from the change pressure, not the pattern name.
- Show how tests protect behavior before refactoring.
- Explain the trade-off between abstraction and readability.

## Strong Closing Point

This project is strongest when presented as evidence of design judgment: knowing
when a pattern helps and when simpler code is the better engineering decision.
