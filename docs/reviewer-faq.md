# Reviewer FAQ

## What should I review first?

Start with the README, pattern catalog, pattern trade-offs, and reviewer
scorecard.

## What is the main technical signal?

The project shows design patterns as practical responses to change pressure,
not as decoration or memorized vocabulary.

## What is intentionally unfinished?

More runnable examples and before-and-after refactoring cases can still be
added for deeper production realism.

## What should we discuss in an interview?

Discuss when patterns improve maintainability, when they create overengineering,
and how tests protect the intent of a pattern.
