# Interview Route

Use this route to navigate the repository during a technical interview.

## Start Here

Open the README and explain that this is a practical Java design patterns lab
focused on backend scenarios.

## Show The Core Examples

Start with Command, State, and Specification. Explain the change pressure each
pattern addresses and point to the tests that prove behavior.

## Discuss Engineering Judgment

Use the pattern trade-offs, anti-patterns, and selection guide to show that
patterns are chosen with restraint.

## Close With The Next Step

Explain that a Template Method retry workflow would add another production-like
example without making the repository too large.
