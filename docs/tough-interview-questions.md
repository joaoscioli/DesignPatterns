# Tough Interview Questions

Use these questions to prepare direct, technical answers.

## How do you avoid pattern overuse?

Start with the change pressure. If the pattern does not make variation,
lifecycle, composition, or decoupling easier to explain, it is probably too much.

## Which pattern is strongest here?

Command, State, and Specification are the strongest because they connect to
backend workflows, lifecycle transitions, and business-rule composition.

## What would you improve next?

Add a Template Method retry workflow and compare it with a simpler helper to
make the trade-off explicit.

## What would you defend in a code review?

Keeping examples small and tested so the pattern intent stays visible.
