# Deep Dive Prompts

Use these prompts to move from a high-level walkthrough into a deeper technical
conversation.

## Prompts

- What change pressure justifies the pattern?
- What behavior must remain stable during refactoring?
- What simpler design was rejected and why?
- How would the pattern evolve if requirements doubled?
- What maintenance cost does this abstraction introduce?

## Strong Discussion Direction

The best answers should show restraint, compare alternatives, and explain how a
pattern earns its complexity through real change pressure.
