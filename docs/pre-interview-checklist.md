# Pre-Interview Checklist

Use this checklist before presenting the repository.

## Review Before The Call

- Open the fast review path and interview route.
- Pick three patterns to discuss: Command, State, and Specification.
- Prepare one example of when a pattern would be too much.
- Know which tests prove each selected example.

## Be Ready To Show

- command dispatch tests
- subscription state tests
- plan upgrade specification tests
- pattern trade-off documentation

## Strong Close

Explain that patterns are useful when they answer real change pressure.
