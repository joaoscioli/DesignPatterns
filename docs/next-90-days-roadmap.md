# Next 90 Days Roadmap

This roadmap shows how the project can grow from study material to stronger
portfolio evidence.

## 30 Days

- Add one runnable example for each priority pattern.
- Expand tests to prove behavior instead of structure.
- Improve pattern selection notes with simpler alternatives.

## 60 Days

- Add before-and-after refactoring examples.
- Group patterns by backend use case: workflow, lifecycle, rules, and boundaries.
- Add a guided comparison between Strategy, State, and Specification.

## 90 Days

- Build a small domain scenario that combines multiple patterns.
- Add a reviewer walkthrough for architecture trade-offs.
- Keep anti-pattern guidance close to every new example.
