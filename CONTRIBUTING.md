# Contributing

This repository is maintained as a design pattern study lab.

## Working Style

- Add one pattern or concept at a time.
- Include a small runnable example when practical.
- Explain when the pattern helps and when it adds unnecessary complexity.
- Keep tests and documentation close to the example.

## Before Opening A Pull Request

- Run the test suite.
- Update the pattern catalog or roadmap when needed.
- Add interview notes when the change introduces a useful trade-off.

## Review Focus

Reviewers should look for simple examples, clear intent, and honest discussion
of trade-offs.
